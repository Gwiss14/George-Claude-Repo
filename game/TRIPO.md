## Export settings (every model)

- Format **GLB**, texture size **2K** for non-heroes (heroes keep their 4K maps).
- Rigged fighters: skeleton **on**, **Number of Animations → Select All** (it starts at 0), **Animation stay in Place → on** (only appears once animations are selected).
- If the Export button does nothing on the first click, click it again.
- Save each file with the name in the `file` column into `game/public/assets/`.

- **sky**: Built in code (done): a banded sunset gradient and a ring of skyline blocks with lit windows.
