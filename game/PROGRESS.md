# Progress

## Done
- Stage 1, Design: GDD.md written ("Lamplight Meadow"). Waiting for feedback.

## Decided
- Player said "surprise me" to all five opening questions, so these are my picks:
  - Theme: a lamplighter (Wick) lighting 8 lanterns on a floating meadow at dusk while fog-creatures (Snuffs) put them out.
  - One action: run. No jump, no fighting.
  - Controls: keyboard and phone.
  - Art style: chunky, soft low-poly toy look, warm dusk colours.
  - Nothing pre-made.
- The game lives in `game/` inside the existing repository (the repository root was not empty), so it uses that repository instead of a new one.
- Snuffs are one-piece bodies animated in code, not rigged.
